# Loja Virtual  QA Lab
Loja virtual para teste em QA

## Executar

Abra o arquivo `index.html` diretamente no navegador. Não é necessário instalar nada: o projeto usa apenas HTML, CSS e JavaScript puro.

O projeto inclui pesquisa, carrinho, checkout, login e cadastro, com atributos `data-testid` nos fluxos principais para uso com Cypress.
